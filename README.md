# 🦖 Dino Clima Dinâmico

Bem-vindo ao **Dino Clima Dinâmico**! Este é o meu primeiro projeto de jogo, desenvolvido com HTML, CSS e JavaScript. É uma versão personalizada e mais desafiante do clássico jogo do dinossauro, onde o ambiente reage ao seu progresso.

## 🎮 Sobre o Jogo

O objetivo é simples: sobreviver o maior tempo possível saltando sobre os obstáculos. A grande diferença? O clima e o ambiente mudam conforme a sua pontuação aumenta, tornando cada sessão de jogo uma experiência visualmente única.

### Funcionalidades Principais
* **Estações Dinâmicas:** A cada 100 pontos, o jogo altera o clima aleatoriamente entre **Outono, Inverno, Primavera e Verão**, garantindo que a mesma estação nunca se repita consecutivamente.
* **Obstáculos Variados:** Além dos cactos clássicos, prepare-se para enfrentar pássaros que exigem reflexos rápidos.
* **Dificuldade Progressiva:** A velocidade do jogo aumenta conforme a sua pontuação sobe.
* **Sistema de Recorde:** O seu melhor desempenho (*High Score*) é guardado automaticamente no seu navegador.

## 🚀 Como Jogar

* **Pular:** Pressione a barra de **Espaço** no teclado ou toque na tela (para dispositivos móveis).
* **Reiniciar:** Após perder, basta pressionar o botão de reiniciar na tela de Game Over.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura base do jogo.
* **CSS3:** Estilização, animações de transição de clima e efeitos visuais.
* **JavaScript:** Lógica de jogo, gestão de colisões e animações de estado.
